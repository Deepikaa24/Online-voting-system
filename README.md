
# 🗳️ Online Voting System

A secure and user-friendly web-based voting system that allows users to register, log in, and cast their votes digitally. 

Designed to streamline the election process with admin control and real-time vote tracking.

---

## 🚀 Features

- 🔐 User Registration and Login (with session-based authentication)
- 📋 Candidate or Group Listing
- ✅ Secure Voting (one vote per user)
- 📊 Admin Dashboard with Vote Count Visualization
- 🧾 Voter and Candidate Management

Tech Stack
Frontend: HTML, CSS
Backend: PHP 
Database: MySQL 
Chart Library: Chart.js or Google Charts (for admin vote graphs)

 Roles
Admin: Add/view groups and monitor results.
Voter: Log in, view groups, and vote once.

Security Features
Password hashing
Session validation
One-time vote locking
Input sanitization to prevent SQL injection
